# Provider icon sources

- `microsoft-outlook.png`: official Outlook favicon from `outlook.live.com`.
- `netease-mail.png`: official NetEase Mail favicon from `mail.163.com`.
- `google-voice.svg`: Google Voice product icon from [Google Voice Help](https://support.google.com/voice/answer/115061), via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Google_Voice_Logo_05.2026.svg).

The other bundled provider marks are imported from the `simple-icons` package.
